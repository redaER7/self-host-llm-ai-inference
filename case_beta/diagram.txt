FLOW 1: INTERNAL API CALL (curl within cluster via KServe Gateway)
══════════════════════════════════════════════════════════════════════════════

  # KServe Gateway is ClusterIP (not publicly exposed).
  # From within the cluster:
  curl http://envoy-kserve-kserve-ingress-gateway-...envoy-gateway-system.svc/beta/qwen-7b/v1/chat/completions \
    -d '{"model":"qwen2.5-7b","messages":[{"role":"user","content":"hi"}]}'

  1. Request arrives at KServe Gateway proxy (ClusterIP, CP node)
  2. kube-proxy routes to envoy-kserve-* pod (Envoy Gateway proxy on CP)
  3. Envoy matches HTTPRoute qwen-7b-kserve-route:
     PathPrefix /beta/qwen-7b/v1/chat/completions
  4. URLRewrite filter: /beta/qwen-7b/v1/chat/completions → /v1/chat/completions
  5. backendRef: InferencePool qwen-7b-inference-pool :8000
  6. EPP pod receives gRPC request, applies scheduler plugins:
     a. prefix-cache-scorer (check cached KV cache for prefix match)
     b. load-aware-scorer (check load, threshold 100)
     c. max-score-picker (select best target)
  7. Forwards to vLLM worker pod on GPU node (10.10.0.2:8000)
  8. vLLM processes inference on GPU, streams response back

  Catch-all (non-scheduler endpoints like /v1/models, /health):
  → backendRef: Service qwen-7b-kserve-workload-svc :8000
  → directly to vLLM pod (bypasses EPP)


FLOW 2: NEXTCHAT CHAT UI (via AI Gateway)
══════════════════════════════════════════════════════════════════════════════

  1. User opens https://nextchat.yacodata.com → CP:30081 → NextChat pod
  2. Browser loads React chat UI
  3. NextChat calls API from browser:
     POST https://envoy-llm.yacodata.com:30080/v1/chat/completions
     Header: x-ai-eg-model: qwen2.5-7b
  4. DNS → 89.167.109.193:30080 → hits CP node
  5. kube-proxy routes to envoy-ai-gateway-* pod (AI Gateway proxy on GPU)
  6. TLS termination at pod (cert: envoy-llm.yacodata.com)
  7. Envoy matches AIGatewayRoute qwen-route:
     header x-ai-eg-model: qwen2.5-7b → InferencePool qwen-7b-inference-pool
  8. Same EPP → vLLM flow as Flow 1

  Note: request goes CP:30080 → Flannel → GPU:AI-Gateway-Proxy
  (the AI Gateway proxy pod runs on the GPU node per EnvoyProxy)
